02.1Semantic method and definition template

Every ORIGIN structure is a pure, causal state machine over an explicitly ordered input stream. A label is accepted only when its definition, availability, identity, transition law, invalidation, and evidence denominator are complete.

Mandatory definition record

  1. Name and version: immutable semantic identifier.
  2. Purpose: what empirical hypothesis it represents and what it does not claim.
  3. Input domain: contract, event kind, timeframe, price source, venue model and quality dependencies.
  4. Units and normalization: ticks, steps, quote notional, bps, event/time windows.
  5. Formation predicate: exact algebra and inclusive/exclusive boundaries.
  6. Origin, confirmation and availability: distinct source IDs and clocks.
  7. Identity material: immutable source occurrence, original geometry and semantic instance.
  8. Lifecycle: states, guards, precedence, revisions and terminal conditions.
  9. Invalidation and expiry: semantic invalidation separate from operational staleness.
  10. Tie-breaks: total deterministic order.
  11. Long/short mirror: algebraic transform and golden vectors.
  12. Evidence plan: denominator, ablations, costs, trial family and falsifiers.
Terminology discipline. If only OHLC price crossed and reclaimed a level, call it level_excursion_reclaim. Terms such as liquidity consumed, stop run, institutional order block, or smart money require direct evidence or remain narrative, not canonical facts.

02.2Input, ordering, bar, and observation model

  • Market inputs arrive as market_state.v2 revisions referencing raw market_event.v2 offsets and connection epochs.
  • Partition key is (venue_model, canonical_instrument_id, semantic_timeframe). One logical writer orders each partition.
  • Cross-connection venue events have no fabricated total exchange order. Recorded local receipt order plus source-specific venue sequence is preserved.
  • A finalized bar is eligible only after its close event is received and its watermark completes. Corrections append a new data revision and cannot rewrite previously available history.
  • Every detector declares accepted observation kind: finalized bar, accepted trade, quote/book revision, or a named composite. Implementations may not switch dynamically.
  • All prices enter semantic code as signed integer ticks under an instrument metadata revision. Overflow and conversion error are fail-closed.

Deterministic transition signature

transition(
  prior_state_bytes,
  ordered_input_envelope,
  immutable_parameter_bundle,
  dependency_quality_snapshot
) -> (new_state_bytes, zero_or_more_events)

No system clock. No I/O. No randomness. No unordered output.

Equal-level anchored clustering

Let the first accepted member price be anchor a, tolerance q ticks, and maximum total span s ticks. A new confirmed pivot p may join only if |p−a| ≤ q and max(all members,p)−min(all members,p) ≤ s. The anchor does not drift. If several clusters accept, choose smallest absolute anchor distance, then earliest cluster origin, then smallest cluster ID.

Session level

A session is a versioned calendar interval in UTC. Its high/low/open derives only from accepted observations within that interval. Changing host timezone, buffer retention, or process restart cannot change it.

02.4Directional-change swing — baseline v1

The initial structural primitive is swing.dc.bar_extrema.v1 over finalized bars. Tick/trade variants are separate formulas.

δx = max(min_reversal_ticks, ceil(|pricex| × reversal_bps / (10,000 × tick_size)), ceil(kvol × trailing_ATR_before_x / tick_size))
  • In an up leg, a strictly higher finalized-bar high replaces the provisional extreme. At that new extreme, freeze a new δ_x using a trailing volatility window ending strictly before the extreme bar.
  • Confirm swing high x only when a strictly later accepted finalized bar produces a low at or below high_x − δ_x. The confirming observation and its availability are recorded; the swing origin remains at x.
  • If an equal high occurs, apply the registered tie rule: baseline v1 retains the earliest extreme. A later-equal variant is a different formula.
  • The down-leg/swing-low algorithm is the exact sign-inverted mirror.
  • Warm-up is incomplete until the full trailing volatility dependency and an initial leg are available. No shortened-window fallback.

Required swing fields

Direction, extreme price ticks, origin source ID/time, δ ticks and its dependency range, confirmation source ID/time, availability/knowledge time, formula/parameter/instrument digests, quality, predecessor swing, and source offset range.

02.5Directional structural-state machine and protected swing

Initialization

After at least two confirmed swing highs and two confirmed swing lows are available, compare each latest same-type pair using structure_equality_tolerance_ticks:

  • BULLISH: latest high > previous high + tolerance AND latest low > previous low + tolerance.
  • BEARISH: latest high < previous high − tolerance AND latest low < previous low − tolerance.
  • RANGE: every other valid combination. Before sufficient pairs: UNINITIALIZED.

Protected-swing advancement — normative baseline

  1. On entering BULLISH, protected_low is the latest confirmed swing low available before the event that established bullish state. continuation_high is the latest confirmed swing high.
  2. A first accepted break of continuation_high emits BOS_UP. The current protected low does not move at the break.
  3. After that BOS, confirmed higher swing lows whose origin is strictly after the broken high's origin become pending_protected_low. If several qualify, retain the greatest origin sequence; ties use confirmation sequence then structure ID. A candidate at or below the current protected low is not eligible.
  4. When a later, newly confirmed continuation high receives its own accepted BOS_UP, atomically promote the pending higher low that was available before that breach to protected_low. If none exists, retain the prior protected low.
  5. A valid accepted break below protected_low emits exactly one CHOCH_DOWN occurrence and enters TRANSITION_DOWN. Later packets cannot relabel it as an earlier opposite BOS.
  6. In transition, the first accepted break of a confirmed bearish continuation low establishes BEARISH; the latest eligible intervening confirmed swing high becomes protected_high.
  7. The bearish rules are exact sign/side mirrors.
Why the two-stage promotion exists. A low is not protected merely because it appeared. It becomes protected only after a subsequent continuation break demonstrates that the market used it as the pullback anchor. This rule is a preregistered hypothesis and must be ablated, not treated as universal truth.

02.6Break operator, BOS, and CHOCH

A break is the first accepted post-confirmation observation that crosses a frozen confirmed level L by buffer b ticks. The accepted observation mode is part of the formula:

  • bar_close.v1: finalized close beyond L ± b;
  • event_hold.v1: qualifying side maintained for at least a fixed event-time interval;
  • n_events.v1: at least n qualifying observations with explicit reset law.

Baseline structure capsules use bar_close.v1. Store the frozen level price, threshold, actual breach price, first breach source ID, acceptance source ID, and availability. Wick-only/sub-threshold crosses are observations, not accepted breaks.

Classification

  • BOS: accepted break of the current continuation level in the current directional state.
  • CHOCH: accepted break of the current protected swing against the state, causing a transition.
  • range_break: accepted break of a rolling/equal/session level when structural state does not authorize BOS/CHOCH.

Each level occurrence can produce at most one accepted break of each registered semantic instance. Duplicate input and restart cannot re-emit it.

02.7Fair-value-gap semantics

For three finalized bars t−2, t−1, t, bullish FVG exists iff:

low_ticks[t] > high_ticks[t−2] + g_min_ticks

Original bullish zone is [high_ticks[t−2], low_ticks[t]]. Bearish is the exact mirror: high[t] < low[t−2] − g_min, zone [high[t], low[t−2]]. It becomes available only after bar t is finalized and watermarked. The formation bar cannot retest itself.

Lifecycle and penetration

PROVISIONAL → CONFIRMED → FRESH → TOUCHED → PARTIAL → MIDPOINT_FILLED → FILLED; alternative terminals: EXPIRED, INVALIDATED.

For a bullish zone with lower z₀ and upper z₁, and registered touch observation price p:

penetration = clamp((z₁ − min(p,z₁)) / (z₁ − z₀), 0, 1)

TOUCHED means penetration >0; MIDPOINT_FILLED means ≥0.5; FILLED means 1. Bearish uses mirrored distance. A zero-width zone is invalid. Displacement quality, minimum gap and expiry belong to the versioned parameter set.

02.8Order-block semantics — causal baseline

An order block is not any large opposing candle. Baseline ob.displacement_bos.v1 requires a selected opposing origin, qualified displacement, and a causally linked confirmed BOS.

  1. Detect a displacement path that begins after a finalized opposing bar and reaches at least D ticks / registered ATR multiple within horizon H, with registered body/range and close-location quality.
  2. Search at most W finalized bars immediately preceding the displacement start for qualifying opposing bars. Choose the latest origin sequence; tie by greater body quote-notional where available, then immutable source ID.
  3. Baseline bullish zone is [low, open] of the selected bearish origin bar. Baseline bearish zone is [open, high] of the selected bullish origin. Full-range/body-only variants are distinct formulas.
  4. Link the displacement to an accepted BOS in the same direction within H. The OB remains provisional until that BOS is available. No BOS means no confirmed OB.
  5. Freeze original geometry and identity at confirmation. Penetration/mitigation revisions retain the ID.

Lifecycle: ORIGIN_CANDIDATE → DISPLACED → CONFIRMED_BY_BOS → FRESH → TOUCHED → PARTIAL → MITIGATED; terminals BROKEN, EXPIRED, INVALIDATED.

The origin selection window, opposing-bar predicate, zone convention, displacement algebra, horizon, tie-break, mitigation threshold, invalidation, touch source and TTL are mandatory version fields.

02.9Level excursion and reclaim

A reclaim references one frozen, already-confirmed typed level; the reference cannot roll during the occurrence.

Support excursion / LONG-oriented reclaim

  1. Level L is available before the excursion.
  2. Registered observation crosses to p ≤ L−e; store excursion extreme and source ID.
  3. Within event-time horizon τ, price returns to p ≥ L+r, where reclaim buffer r is versioned.
  4. Hold inside for n qualifying observations or one named finalized-bar rule without crossing the invalidation bound.
  5. Only after hold completion emit RECLAIM_CONFIRMED.

The resistance / SHORT-oriented rule is the exact mirror. Lifecycle: ARMED → EXCURSION_OBSERVED → RECLAIM_PENDING → RECLAIM_CONFIRMED → REACTION_ELIGIBLE → CONSUMED; terminals EXPIRED, INVALIDATED.

With price-only data, evidence supports “excursion and reclaim,” not liquidation, stop consumption, or intent.

02.10First retest, first touch, and maker eligibility

A qualifying first retest/touch requires all of:

  • structure is confirmed and available;
  • touch event is strictly later than formation/confirmation;
  • minimum departure is satisfied in registered ticks plus either event count or event-time duration;
  • the structure remains fresh and not invalidated/expired;
  • the occurrence has no prior qualifying touch under the same formula instance.

Contact boundary and price source are explicit. At the first qualifying contact, atomically append the touch transition before evaluating downstream reactions, so duplicate or simultaneous observations cannot create two candidates.

Maker distinction. An order may be posted before contact when a capsule emits first_touch_eligibility. That is an execution opportunity, not proof the market retested or the order filled. Structure touch, order placement, and venue fill remain separate events and denominators.

02.11Microstructure confirmation atoms

Flow atoms are linked evidence with their own clocks, quality, TTL, formula and identity. They may confirm or veto a reaction only in a separately registered capsule variant. They never redefine price structure.

Baseline atoms

  • Trade-flow imbalance: signed aggressor quote notional over exact event-time windows, TFI=(buy_quote−sell_quote)/(buy_quote+sell_quote); zero denominator is null.
  • Order-flow imbalance: event-by-event best-level contribution using venue absolute quantities and exact book sequence; aggregate over registered 100ms/1s/5s windows.
  • Book tilt: (bid_quote_depth−ask_quote_depth)/(bid_quote_depth+ask_quote_depth) inside exact tick-distance bands; invalid/crossed/empty book is null.
  • Liquidation impulse: signed venue-supported liquidation quote notional with explicit source coverage. Missing/retired stream is degraded, never zero.
  • Exhaustion: preregistered relation between antecedent impulse and diminishing price/flow response; it is not a narrative label.

Every atom stores source watermark, horizon, numerator/denominator, units, freshness deadline, missing reason, and dependency quality. Cross-venue atoms additionally store measured clock uncertainty and never use a later venue update early.

02.12Reaction evaluation and candidate construction

Structures exist independently of trades. A reaction is a separate hypothesis evaluation:

LocationPrice intersects eligible frozen geometry
FreshnessLifecycle and TTL valid
DepartureRegistered separation met
TriggerFirst touch/reclaim/break condition
ConfirmationOptional fresh flow atom
GeometryEntry, natural invalidation, causal target

Candidate admission

  • Entry reference is a deterministic tick price/range, not an executable order.
  • Natural invalidation is structure-derived and frozen at candidate publication.
  • Targets must already exist or be a preregistered deterministic R transform; no future-chosen target.
  • Candidate geometric reward/risk must be at least 2.0 before costs; E07 may impose a stricter economic threshold.
  • Candidate carries TTL, not_before, cancel/withdraw conditions, cost-model references, capability prerequisites and complete lineage.
  • ORIGIN emits no account, leverage, quantity, risk approval, venue command, or expected return invented from missing calibration.

Isolation law

Each capsule runs alone during initial economic evaluation. A capsule variant that adds flow, regime, or a second structure is a new preregistered trial. Opportunity clustering prevents simultaneous aliases from being treated as independent confluence. E07 chooses at most one money hypothesis per opportunity/risk cell.

The parameter bundle is canonical JSON or another byte-canonical approved format. Hashing uses the exact canonical bytes; comments and environment overlays cannot change semantic values outside the signed bundle. Every output includes formula_version, parameter_set_id, and parameter_digest.

No legacy-value inheritance. RC1 deliberately leaves numeric detector thresholds symbolic. Values enter only through registered trials and a signed activation manifest. A code default is a hidden experiment and therefore forbidden.

02.16Semantic proof obligations

  • Prefix invariance: replaying a prefix alone and the same prefix followed by arbitrary future events yields identical confirmed outputs through the prefix watermark.
  • Restart invariance: cold, warm, and checkpoint-resumed runs yield byte-identical suffix events and IDs.
  • Duplicate invariance: retransmission changes no semantic state or count.
  • Mirror property: sign-invert prices, swap bid/ask and LONG/SHORT; mirrored outputs have identical timing, counts and normalized geometry.
  • Scale metamorphism: valid tick/step-preserving price/quantity rescaling changes only physical units, not normalized decisions.
  • Lifecycle monotonicity: state sequence strictly increases; terminal states cannot re-enter active states.
  • Identity stability: mutable geometry, logging, trace, wall clock, process ID, thread count, iteration order and deployment instance do not change occurrence ID.
  • Risk independence: changing E08 stop floors, leverage or budget cannot alter ORIGIN structures.
  • Null honesty: deletion of a dependency creates named abstention, never a default value.
  • Falsification: placebo timestamps/signs, future mutation, ablations and parameter-neighborhood tests must be capable of destroying an apparent edge.
