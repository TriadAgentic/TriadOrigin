07.1How to use this checklist

This is the execution companion to the normative specification. Checking a box is a local working aid, not a governed PASS. A task is complete only when its acceptance evidence exists, the accountable owner signs it, and the applicable gate receipt references the evidence hash.

  • Do tasks in dependency order; a later phase may prototype in parallel but cannot claim the earlier gate.
  • P0 is release-blocking. P1 is required for the named phase gate. P2/P3 may be deferred only through the Decision Register.
  • Every discovered task receives a new ID; never repurpose an existing ID.
  • Export progress JSON/CSV for review. Browser-local completion state is non-authoritative and can be reset.
