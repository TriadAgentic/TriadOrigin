06.2Inventory control rules

  • This is a bill of materials and authority register, not proof that an item is deployed or healthy.
  • Every item has one accountable owner role before Phase −1 exit. “Shared” requires a named primary owner and secondary reviewers.
  • Repository/source, deployment, runtime activation, producer authority and evidence completeness are separate facts.
  • Secrets are inventoried by identifier, owner and rotation—not by value.
  • Items marked BUILD/REPAIR/BLOCKED need checklist tasks and acceptance evidence. RETIRE items need drain, consumer, retention and removal proof.
  • Changes update the inventory and its CSV in the same governed specification revision.
