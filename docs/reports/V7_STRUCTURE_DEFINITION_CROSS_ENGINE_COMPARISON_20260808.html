Proven net alpha

Code similarity and architecture quality do not establish profitable live EV.

Closest true lineage

QuantTrade ↔ YoloBot legacy SMC share essentially the same centered-pivot SMC family. YoloNaut ↔ Newnaut live V2 share the prior-20 BOS/retest and sweep-reclaim feed logic.

Closest geometric convergence

YoloNaut, Newnaut, active YoloBot, and TRIAD all use rolling extrema in some form. Their window, confirmation, state, and reaction differ enough that they are not the same strategy.

Most misleading shared word

“Sweep.” It can mean a wick through a pivot, a prior-20 excursion, a 90-second print breach, a one-second taker-flow burst, or merely historical penetration beyond an equal level.

Blunt conclusion: Newnaut has the richest vocabulary, TRIAD has the strongest chassis, UPONLY/Pulse have the clearest short-lived event states, and YoloNaut/Newnaut have the best first-retest reaction. None provides a complete, causally correct structure system that should be copied wholesale.

05 · Deep dive

Swings and levels: the root dependency

If the reference level is wrong, BOS, CHOCH, order blocks, sweeps, stops, and targets all inherit the error.

Centered pivot familySH(i) ⇔ Hᵢ = max(Hᵢ₋ᵣ … Hᵢ₊ᵣ)

Quant uses r=5; Newnaut legacy uses r=10; YoloNaut’s dead/predictive files use r=3, explicit r=5, and a primitive default r=10. The pivot occurs at i but is only available at i+r.

Rolling-extreme familyL_high(t) = max(Hₜ₋ₙ … Hₜ₋₁)

YoloNaut/Newnaut use n=20; active YoloBot uses previous 20; TRIAD uses the full retained buffer. It is causal but not inherently a structural swing.

Event-extreme familyL_high(t) = max(print price in t−90s … t⁻)

UPONLY reads the lagged 90-second extreme before inserting the current print. This is suitable as a fast level class, not a replacement for higher-timeframe swing structure.

Why a single “swing” field is unacceptable

  • A centered pivot is delayed but locally stable.
  • A prior-N extreme is immediate but changes as the window rolls.
  • A directional-change extreme is stateful and event-threshold based.
  • A session/equal-high level has different provenance and expected reaction.

Mixing them destroys attribution and makes parameter tuning uninterpretable.

V7 canonical decision

Emit typed level atoms: swing.dc.v1, swing.fractal.v1 (experimental), rolling_extreme.v1 (baseline), equal_level.v1, and session_level.v1. Never collapse them into one swing field.

Primary state structure should use directional-change swings: update an extreme in the active direction, confirm it only after an opposite move of δ, and store both origin and confirmation time.

All identity geometry is integer ticks: p̂ = round(price / tick_size_snapshot)

At each new provisional extreme, freeze:
δ_origin = max(min_ticks,
               ceil(min_bps × reference_price_ticks / 10,000),
               ceil(atr_multiplier × ATR_ending_before_origin / tick_size))

up-leg:   extreme = max(extreme, price)
confirm swing-high when a strictly later finalized close ≤ extreme − δ_origin
down-leg: extreme = min(extreme, price)
confirm swing-low  when a strictly later finalized close ≥ extreme + δ_origin

This is a definition, not a profitability claim. δ families must be preregistered and evaluated independently. Directional-change research supports event-based segmentation, but it does not prove that this particular crypto scalping reaction is profitable.

ClassificationBOS = break in state direction

CHOCH is a state transition derived from the same break operator. It is not “the last opposite BOS,” proximity to a level, or a second detector.

bullish state:
  protected_low = last confirmed structural low
  close/hold above continuation_high + b  → BOS_UP; state remains bullish

bearish state is the exact mirror.
One break occurrence emits once. A transition cannot predate its source break.

12 · V7 constitution

Canonical definitions to ratify before implementation

These are proposed version-1 hypotheses. Parameters are versioned and preregistered; definitions cannot drift under the same detector ID.

Typed level

Every reference has a kind, geometry, origin, confirmation, availability, provenance, timeframe, version, quality, and stable ID. Rolling extreme, swing, equal high/low, and session level remain distinct.

Integer-tick geometry

Prices are normalized with the instrument tick-size snapshot before comparison or hashing. Floating-point prices cannot determine boundaries or persistent identity.

Directional-change swing

Primary structural swing confirms only after reversal by versioned δ. It stores extreme time and confirmation time separately. Fractal and rolling-extreme alternatives remain independent benchmark types.

BOS

First accepted break of a confirmed continuation level in the current structure direction. Stores broken level and breach price separately. One occurrence emits once.

CHOCH

The same break operator applied against the current protected swing, causing a state transition. Never derived by searching for an older opposite BOS.

FVG

Three closed bars, explicit minimum gap, unavailable until bar three closes, and monotonic fill lifecycle. Formation bar cannot be its own retest.

Order block

Last selected opposing origin before qualifying displacement that causally produces confirmed BOS within horizon H. Provisional until the BOS confirms.

Level excursion / reclaim

Confirmed level is crossed by e, price returns inside within τ, then holds for n events or a closed bar. Without order-book/trade evidence, never call this proof of consumed liquidity.

First retest

First qualifying contact after confirmation and minimum departure. Pre-positioning a maker order is first_touch_eligibility; it is not evidence that a retest already happened. Any later touch is touch number 2+, not another first retest.

Microstructure confirmation

OFI, TFI, delta, book tilt, liquidation, and exhaustion are linked atoms with their own TTL and data-quality state. They do not redefine the underlying price structure.

Reaction and candidate separation

A structure may exist without a trade. Reaction evaluates location, freshness, trigger, confirmation, and risk feasibility before emitting one complete hypothesis.

Monotonic lifecycle

No filled FVG becomes fresh, mitigated OB becomes unmitigated, consumed level becomes unconsumed, or expired occurrence becomes live because a rolling window moved.

Exact mirror symmetry

Long and short definitions are algebraic mirrors unless a preregistered asymmetry is explicitly tested. Generic score inequalities are forbidden.

Risk-policy independence

Structure and trigger geometry cannot read portfolio or stop-width policy. V7 records the setup’s natural invalidation; E08 can deny or size it, but a risk-floor change cannot alter which structure existed.

14 · Acceptance tests

Structure truth before performance

A profitable backtest cannot rescue a detector that repaints, duplicates, changes meaning, or consumes the wrong timeframe.

Causality

  • Prefix replay invariance.
  • No event before confirmed_at.
  • No future bars in historical baselines.
  • No forming bar in confirmed structure lane.
  • Gap/data discontinuity fail-closed.

Identity & lifecycle

  • Same source geometry → same ID.
  • One occurrence emits once.
  • States move only forward.
  • First retest count exactly one.
  • Consumed/expired objects never re-arm.

Directional correctness

  • Long/short algebraic mirror.
  • Protected level correct by state.
  • Broken level ≠ breach close.
  • Stop/invalidation on correct side.
  • Separate denominators by side.

Timeframe & data

  • Actual timeframe carried in contract.
  • Scheduler cannot relabel data.
  • Duplicate timestamp rejection.
  • Sequence/watermark continuity.
  • Stale/missing flow is not zero flow.

Authority

  • One registry names the live implementation.
  • Dead code cannot appear in live claims.
  • One producer lease/epoch for money.
  • Detector version binds formula + parameters.
  • Config and deployed digest agree.

Economic measurement

  • Structure → reaction → candidate → fill lineage.
  • Entry/exit role and symbol on fill.v2.
  • Net costs and maker/taker truth.
  • MFE/MAE from point-in-time events.
  • Sealed holdout and multiplicity control.

Promotion law: semantic correctness is necessary but not sufficient. Every capsule must then survive same-stream replay, prospective dark run, cost/fill modeling, sealed holdout, and isolated canary. No structure gets authority because it “looks institutional.”
